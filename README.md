# Madinat Aspace — GTA Solarpunk (Option A · WebGPU/WebGL + Three.js + Zustand)

Prototype jouable (« Vertical Slice ») de la **3ème Interface 3D World** d'Aspace Marketplace, fusionnant la **Ville Ronde de Bagdad (*Bayt al-Hikma*)** et **Apple Park** dans un monde ouvert Solarpunk où chaque bâtiment est entrable et exploitable.

## Lancer le Monde 3D

```powershell
cd C:\Users\amado\.gemini\antigravity\scratch\madinat-aspace-solarpunk
npm run dev
```

Puis ouvrir `http://127.0.0.1:5194`.

## Contrôles « GTA Solarpunk »

- **`ZQSD` / `WASD` / Flèches** : Se déplacer à pied ou piloter un véhicule (Supercar, Glisseur, eVTOL)
- **`Shift`** : Sprint / Turbo Solaire
- **`Espace`** : Sauter (à pied) / Prendre de l'altitude (en eVTOL)
- **`C`** : Basculer Vue 1ère / 3ème personne (à pied) ou Descendre (en eVTOL)
- **`E`** : Action contextuelle (monter/descendre d'un véhicule, ouvrir un pupitre métier des 8 départements, frapper le Gong d'Or, recruter un candidat IA, signer l'Escrow `S0`, intercepter le Drone Fantôme, plonger dans un Tableau-Portail Mario 64)
- **`F`** : Sauter en **Parachute Solaire** depuis l'aéronef eVTOL en plein vol
- **`N`** : Téléportation instantanée vers le prochain agent ayant besoin d'une validation humaine (*Next Agent Needing You*)
- **`P`** : Ouvrir le **Smartphone CEO Dynamic Island** (Chat `A0 Amadeus`, Radio Solarpunk synthétisée, Time-Lapse `60× / 600×`)
- **`B`** : Ouvrir le **Mode Architecte In-World** (matérialiser en direct ou à la voix des kiosques, fontaines *Qanat*, bosquets et tours *Badgir*)
- **`1` / `2` / `3` / `4`** : Bascule instantanée `< 0,5 s` entre `Digital Garden`, `Pro Web Desktop`, `3D GTA Solarpunk` et l'`Inspecteur Maquette .GLB Originale` (`1 453 978` triangles ré-éclairés).
